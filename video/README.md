# 시연 영상

Pleos Connect 에뮬레이터(API 34) 화면을 1920×1080으로 녹화했다. 왼쪽이 마중 앱, 오른쪽이 내비.

| 파일 | 길이 | 내용 |
|---|---|---|
| `시연_실제동작_1부.mp4` | 49초 | 음성 포함. 코엑스 1.5km 안 → 브리핑 음성 → "응" → 내비 목적지를 봉은사 공영주차장으로 변경 → 기어 P → "몇 층 어디에 세우셨어요?" → "지하 2층" 기억 |
| `시연_실제동작_2부.mp4` | 30초 | 1시간 40분 뒤 기어 D → 출발 요약 음성 → 집 → 안내 시작 → 내비 목적지 화서역 |

## 알아둘 것
- 운전자 대답은 마이크 대신 앱의 시연용 음성 파일(`demo_reply.pcm`, `demo_spot.pcm`)로 넣어 영상에서는 들리지 않는다.
- 2부의 "1시간 40분"은 앱에 저장된 주차 시각을 100분 앞당겨 만든 것이다.
- 2부 앞 1초는 기어 D 전 화면(더미 문구 "더현대 서울")이다.
- 에뮬레이터 내비는 위치가 판교에 고정이라 남은 거리가 줄지 않는다. 브리핑은 GPS(`adb emu geo fix`)를 목적지 근처로 옮겨 띄웠다.
